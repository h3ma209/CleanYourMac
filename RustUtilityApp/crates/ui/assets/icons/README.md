# UI icons

Lucide 0.544.0, [ISC license](https://github.com/lucide-icons/lucide/blob/0.544.0/LICENSE).

Upstream files: <https://github.com/lucide-icons/lucide/tree/0.544.0/icons>

These are the original Lucide SVGs (`fill="none"`, `stroke="currentColor"`). The UI tints them at draw time with the caller color. No color is baked into the files.
